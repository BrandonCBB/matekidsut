# MateKids UT

MateKids UT es una aplicación web educativa desarrollada como proyecto académico en la Universidad Tecnológica de Cancún. Está enfocada en apoyar el aprendizaje de las matemáticas en estudiantes de educación primaria en México.

## Objetivo

Ofrecer una plataforma gratuita e interactiva para practicar operaciones matemáticas de una manera sencilla y accesible.

## Funcionalidades principales

- Práctica de sumas, restas, multiplicaciones y divisiones.
- Ejercicios matemáticos interactivos.
- Acceso para alumnos sin necesidad de crear una cuenta para practicar.
- Panel para docentes y seguimiento de ejercicios.
- Administración de usuarios y roles.

## Tecnologías utilizadas

- **Frontend:** HTML, CSS y JavaScript.
- **Backend:** Node.js y Express.
- **Base de datos:** MySQL.
- **Herramientas:** Visual Studio Code, Git y GitHub.

## Instalación

1. Clonar este repositorio.
2. Instalar Node.js y XAMPP.
3. Configurar la base de datos MySQL.
4. Configurar las variables de entorno necesarias.
5. Instalar las dependencias del backend con `npm install`.
6. Iniciar el servidor según la configuración del proyecto.
